# Accidentalidad Vial Bucaramanga

Aplicación Flutter para consultar y visualizar los accidentes de tránsito de Bucaramanga. Proyecto Pedagógico Integrador del Tecnológico de Antioquia.

```
flutter pub get
flutter run -d chrome
flutter test
```

- [Contexto técnico](docs/CONTEXTO_TECNICO.md): arquitectura, algoritmos y complejidad.
